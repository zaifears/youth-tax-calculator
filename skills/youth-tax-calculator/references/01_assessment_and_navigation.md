# NBR e-Return: Assessment & Navigation Guide (Chapter 4)
*Source: NBR eReturn System User Manual (Pages 23-27)*

## Key UI Constraints
1. **Return Scheme:** Universal Self (Section 180).
2. **Assessment Year:** Pre-set (e.g. 2026-2027 for Income Year 1 July 2025 – 30 June 2026).
3. **Resident Status:** Resident.
4. **Tax Exempted Income Lock:** Must toggle **Any income which is fully exempted from tax? -> Yes**. If set to No, the entire Tax Exempted Income left-hand tab is hidden by Angular SPA logic.
5. **SPA State Retention:** Never use F5 or browser Back. Always use **Save & Continue**.
