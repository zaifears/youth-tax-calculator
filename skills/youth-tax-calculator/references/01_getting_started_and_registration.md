2. Getting Started 
2.1. What’s in this Chapter? 
2.2. Accessing the system for the first time 
Online Income Tax Return file processing is one of the cornerstones of today’s digital Bangladesh. 
Income tax file submission is an easy way to submit returns – and this manual will show you how to 
process the income tax file. The system is simple, smart, and easy to use and helps to taxpayers to 
prepare an accurate tax return without missing any potential tax benefit. These are the details of 
the income tax Return file submission process. 
In order to access the eFiling system, run a web browser and type the URL in the address bar, and 
press enter. The URL is: 
www.etaxnbr.gov.bd


### [Page 5]

Once the URL has been entered, the system will display the following “Home Page” screen: 
 
 
 
Above the screen we have six different system related to online Tax. They are: 
1. eTIN – The eTIN, short for “Electronic Taxpayer Identification Number”, If you have not taken 
eTIN number before, click here to get eTIN first, then sign in to eFiling system with that eTIN. 
 
2. eReturn – Register as a taxpayer, File your tax return. Pay your tax online, Update your tax 
payment. Submit return and get tax record and apply for time petition. 
Figure 1: Home Page of eReturn System


### [Page 6]

3. eTax Payment - eTax payment is a facility provided to the taxpayers to make income 
tax payments through the internet, using Net-banking/Debit card of the selected Bank. In other 
words, E-Tax payments are the direct taxes payable online by the taxpayers. 
 
4. eReturn Ledger - A tax ledger provides a space to record information relevant to taxes, for ease 
of record keeping throughout the year. It can include fields for income, deductions, payments 
to tax agencies, and other data that may be important for tax accounting. Update your tax 
payment if you are a withholding agent. Withholding Tax is a tax which is deducted at source 
by a withholding agent. A withholding agent may be an individual, corporation, partnership, 
trust, association, or any other entity, 
 
5. eTDS- Taxpayer making payments (specified under Income Tax Act) to third parties (deductees) 
are required to deduct tax at source (Tax Deducted at Source -TDS) from these payments. Post 
deduction, the payments must be deposited at any of the designated banks. If TDS is deposited 
by online, it is called eTDS. Manage your source tax (this option is for withholding agents). 
 
6. eTax Service- Services available to a taxpayer through online will be included in this section. 
Interact online with tax support team. T he National Board of Revenue (NBR) organize d a 
nationwide special support service to help taxpayers submit their income tax returns through 
online under eTax Service. 
 
This document is written only for the ‘eReturn’ system, which will guide a taxpayer for 
online Return submissions.

### [Page 12]

New Taxpayer Registration Process in the eReturn System 
At the very beginning of eFiling system when you enter in the browser www.etaxnbe.gov.bd, then 
the home screen of the website will be displayed, if you click on the eReturn of this screen, the 
following page will appear. We will start the taxpayer registration process by clicking on the 
Registration button at the bottom right of this screen. 
 
 
 
 
Password must be at least eight characters long. It must contain at least one lower 
case, upper case, digit (0-9) and special character (@, #, %, &, etc.). The system will 
guide you if using a laptop or desktop computer. 
 
Figure 7: Taxpayer Registration process in the eReturn system


### [Page 13]

Registration in e-return system requires TIN and mobile phone number registered in 
your name (biometrically verified). You can check whether your mobile phone number 
is verified or not by dialing *16001# from your phone. 
 
For registration process follow the 3 steps below: 
 
Step-1: At first click on Registration button then the system will display the following screen 
Step-2: First you enter your 12-digit TIN number, Mobile number (without zero) which you used 
for online TIN registration and enter Captcha code then click on the ‘Verify’ button. Then the 
system will display the screen (Figure-09) in next page. 
 
Important: If you are not using the phone number with which you opened the 
TIN, then register with any mobile phone number registered in your name 
(biometrically verified). 
 
Figure 8: New Taxpayer Registration - Sign Up (Step-1)

Step-3: You will get an activation code on your mobile phone (OTP-One Time Password), type that

button. Then the following screen will be shown: 
 
Your registration is completed. You just need to click on ‘Sign in’ button. Now you can start your 
eReturn process by Signing in into the system.

get the password. You will set your own password during registration. You can log-in to the 
e-return system any time after using your TIN and this password. 
 
Follow the 3 steps below to sign in to the eReturn system: 
 
Step-1: Visit NBR's eReturn system (e-Return System) and click on second option eReturn then 
the system will show the following Sign in screen. 
 
 
 Note: Many features are provided to make e-return easy and user-friendly, many of 
which are not available on mobile devices. So do e-return on laptop or desktop 
computer.

3.5. eReturn Home Page 
After signing in into the eFiling system, the following screen will appear, this is called Home Screen. 
From this part we will do all the work from submitting the return of eFiling. 
 
 
 
 
 
 
 
 
 
 
 
 
 
There are four menus in the home screen, they are as follows: 
 
1. Home 
2. Return Submission 
3. Tax Record 
4. Time Extension 
 
 Important: You can prepare your paper return using the e-return system. Based on 
the information provided by you, the e-return system will accurately generate your 
return, which you can print and submit to Circle. Online verification of source or 
advance tax requires connectivity (API) with other systems. Implementation of API is 
in progress, after completion of which taxpayers paying tax at source or advance will 
be able to submit returns online. 
 
Figure 17: eReturn Home Page

Menu Menu Description 
1. Home No matter which screen’s you are on, clicking home will bring you back

2. Return Submission For online Return submit click on this menu. 
 
3. Tax Record TIN Certificate : After completing of return submit a taxpayer can 
 download the TIN certificate from this option.

 download the Tax certificate from this option. 
Acknowledgement : Acknowledgement is a document of proof of 
 online return submission. A taxpayer can 
 download the acknowledgement slip from this 
 option. 
Verification Slip : After return submission system will generate a 
 online link, through this link anyone can verify 
the 
 tax submission. The taxpayer can download the 
 verification slip. 
Return : Taxpayer can download the whole return file. 
Challan : If you pay the tax through online you can

History Menu : Your tax return submission through online for

 Note: No need to attach anything while filing online return. You sit down with 
the necessary documents and make accurate entries in the required fields , 
that's all you have to do, the rest will be done automatically by the system. As

system, and you will get the receipt. The tax certificate will also be generated 
immediately. By clicking on the Tax Records menu on the left side, you can take 
a print copy of receipts, tax certificates and returns at any time.
