# NBR e-Return: Assets & Liabilities (IT-10B) Zero-Difference Math
*Source: NBR eReturn System User Manual (Pages 48-62)*

## The Mandatory Zero-Difference Equation (Manual Page 61-62)
\text{Total Fund Outflow} - \text{Total Source of Fund} \equiv 0.00

1. $\text{Change in Net Wealth } (\Delta W) = \text{Closing Net Wealth} - \text{Opening Net Wealth}$
2. $\text{Total Fund Outflow} = \Delta W + \text{Living Expenses (IT-10BB)} + \text{Other Outflow}$
3. $\text{Total Source of Fund} = \text{Taxable Income} + \text{Exempt Income} + \text{Other Receipts}$
4. Balancing Formula:
   \text{Other Receipts (Parental Support)} = \text{Total Fund Outflow} - (\text{Taxable Income} + \text{Exempt Income})

## Critical Rules
- **Gifted Gold (Manual Page 51):** Value can be declared as 0 if acquisition cost is unknown.
- **Section 70 PDF Discrepancy:** Line 7 Gross Wealth in PDF summary deducts carried-forward loss from receipts, while Line 10 Total Assets shows full assets. This is an internal Synesis IT reporting math artifact, not a taxpayer error.
