### [Page 96]

8.6. Challan 
 
A challan or bank challan is defined as an official document, form, or piece of paper used to 
credit money from one account to another. It is almost similar to the deposit slip available in 
the bank with which you can deposit money into someone's account in cash. 
 
If you want to ‘Print’ or ‘Save’ the Challan as PDF format, follow the 4 steps: 
 
Step-1: Under Tax Record Menu Click on Challan then the following screen will appear. 
 
 
Step-2: Click on “Click here” option on the right side of the above screen then the system will show 
the following screen. 
Figure 110: Tax Record- Challan


### [Page 97]

Step-3: Click on Print Voucher 
Figure 111: Tax Record-Challan


### [Page 98]

You can print the file choosing print option by clicking top right side of the screen.

8.7. History 
If you want to see your previous Record which was submitted by online, then follow the 3 steps: 
Step-1: Under the Tax Record Menu click on History Menu. 
 
Step-2: Select a record type from Record Type drop down list and select Assessment Year and 
then click on View button 
 
Step-3: Here system not showing the assessment year because this return is filling first time in the 
online system, next year when you file return by online then you can see the year. 
 
Note: Here Software has single screen, but I have shown two screens. Although I have submitted 
Return but in the second screen no Assessment year showing, and View button is inactive. If the 
return is submitted online, the history will not be visible for that year and history will be seen next 
year.

9. Requesting Time Extension 
9.1. What’s in this Chapter? 
 
If it is not possible to file the income tax return by the last date of filing, an application for 
extension of time can be made by showing valid reasons. 
 
Follow the 3 steps for Time Extension: 
Step-1:In the ‘Home Screen’ click on Time Extension 
 
Figure 116: Time Extension Menu


### [Page 101]

Step-2: In the below screen you have to give the date till which date you want to extend the time 
and show the reason for extending the time. Click on the ‘Submit’ button. 
 
Step-3: When you click on Submit button then system will show the following screen and if you 
want to submit Time extension request click on Yes button, if not click on No button. 
 
Figure 117: Time Extension Submit 
Figure 118: Time Extension Warning to Submit
